Manage Docker Sandboxes per project: set up, connect, inspect and tear down.

Usage: sbxm [OPTIONS] <COMMAND>

Commands:
  init        Create the global configuration for sbxm
  add         Register a GitHub repository and build its sandbox
  sync-files  Re-place the files declared in the global configuration into a running sandbox
  rebuild     Apply the edited Dockerfile by recreating the sandbox
  open        Start the sandbox if needed and connect to it over SSH
  stop        Stop running sandboxes
  ls          List managed projects and their sandbox state
  status      Diagnose the host environment or a single project, read-only
  destroy     Delete the sandbox and drop sbxm management data for a project

Options:
      --lang <ja|en>  Display language for this run (ja, en)
  -h, --help          Print help
  -V, --version       Print version
