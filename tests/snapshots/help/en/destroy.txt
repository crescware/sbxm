Delete the sandbox and drop sbxm management data for a project

Usage: sbxm destroy [OPTIONS] [owner/repository]

Arguments:
  [owner/repository]  Target project as owner/repository

Options:
  -f, --force         Skip data-protection and active-session checks, then delete
      --lang <en|ja>  Display language for this run (en, ja)
  -h, --help          Print help
